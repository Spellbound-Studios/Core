# Security

## Supported versions

Security fixes are made on this repository's working branch, `beta` where it exists and `main` otherwise, and reach `main` through a release.

## Reporting a vulnerability

Report a vulnerability privately. In a public repository, use GitHub's private vulnerability reporting: open the Security tab and choose "Report a vulnerability"; only the studio's maintainers can read the report. In a private repository, which only the studio's members can open, report it through the Bug form. Never report a vulnerability in a public issue, a pull request or a public chat, because that tells everyone before a fix exists.

Say which version or branch you found it on, the Unity version and the operating system you used, what someone could do with the vulnerability, and the steps that show it, with a small project if one helps. A suggested fix is welcome but not needed.

## What happens next

The studio acknowledges your report within 7 days and gives you a fix or a decision within 90 days. A fix lands on the working branch through a pull request and reaches `main` with the next release.
