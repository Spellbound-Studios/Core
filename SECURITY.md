# Security

## Supported versions

Security fixes are made for the current major of Core on its `beta` and `main` branches, and for each shipped major on its `release-<major>` branch. A version that none of these branches carries gets no fix, so upgrade to one that does.

## Reporting a vulnerability

Report a vulnerability in Core privately, through GitHub's private vulnerability reporting on this repository: open the Security tab and choose "Report a vulnerability". Only the studio's maintainers can read the report. Never report a vulnerability in a public issue, a pull request or a public chat, because that tells everyone before a fix exists.

Say which version or branch you found it on, the Unity version and the operating system you used, what someone could do with the vulnerability, and the steps that show it, with a small project if one helps. A suggested fix is welcome but not needed.

## What happens next

The studio acknowledges your report within 7 days and gives you a fix or a decision within 90 days. A fix ships as a patch release, and the changelog notes it under Security.
